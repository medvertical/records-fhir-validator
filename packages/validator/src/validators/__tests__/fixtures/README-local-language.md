# Local display language controls

The four mii-nlp and mii-ingredient JSON fixtures are byte-identical published terminology metadata from MII dokument#2026.0.1 and medikation#2026.0.1 in the locked MII definition catalog. They contain CodeSystem/ValueSet definitions, never clinical resource payloads. Original paths and SHA-256 pins are recorded in the Loop76 evidence packet.

NLP has resource language de-DE and an English designation. Ingredient has no resource language, so its default display cannot establish the requested language. Neighbor editions, opaque filters and lifecycle mutations in tests are synthetic authority controls, not asserted published terminology editions.
