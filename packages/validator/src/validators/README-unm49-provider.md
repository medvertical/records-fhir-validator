The pinned source explicitly implements `class =` and `type =` using each row's country/region class and English labels as `name (abbreviation)` when an abbreviation exists, otherwise `name`. Only listed rows establish code membership or a class mismatch. Unlisted codes, unsupported filters, modified snapshots and unavailable display languages remain unknown. Selected registered, cached, package and host CodeSystems retain priority, including incomplete sources. Failed or unusable declarations block fallback. Provider descriptors are detached with dependency capture and checked for the initiating source/tenant/FHIR/pin scope and exact snapshot integrity before use.
